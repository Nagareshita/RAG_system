# LangGraph Workflow Key Registry

## Common Keys (System-wide)

### `user_input`
- **Description**: ユーザーの入力テキスト（システムが設定）
- **Type**: `str`
- **Required**: True
- **Generated by**: system
- **Consumed by**: analyzer, retriever, domain_expert, validator, router, refiner

### `iteration_count`
- **Description**: イテレーション回数（システムが管理）
- **Type**: `int`
- **Required**: True
- **Generated by**: system
- **Consumed by**: router

### `execution_count`
- **Description**: ワークフロー実行回数カウンター
- **Type**: `int`
- **Required**: False
- **Generated by**: router
- **Consumed by**: router

### `execution_history`
- **Description**: 実行履歴リスト（最大10件保持）
- **Type**: `list`
- **Required**: False
- **Generated by**: router
- **Consumed by**: router


## Node Type Keys

- **Description**: 分析されたユーザーの意図
- **Type**: `str`
- **Generated by**: analyzer
- **Consumed by**: retriever, domain_expert, router

#### `optimized_query_{node_id}`
- **Description**: 最適化された検索クエリ

- **Generated by**: analyzer
- **Consumed by**: retriever

#### `confidence_{node_id}`

- **Consumed by**: router, validator
