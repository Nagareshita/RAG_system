包括的技術文書：Modelicaによる冷蔵庫モデルの構築

概要

本技術文書では、Modelica Standard Library (MSL) を用いて家庭用冷蔵庫の動的モデルを構築する方法を包括的に解説する。冷蔵庫は、熱流体系 (Fluid)、熱伝達系 (Thermal)、制御系 (Control)、および電気機械系 (Electromechanical) の統合システムであり、これをModelicaのマルチドメインモデリング環境において再現することを目的とする。

本書は、専門家分析 (Node 4, Node 5) に基づき、冷媒循環系・熱交換器・断熱庫内・制御ロジック・電力消費モデルを統合する設計を提示し、理論的背景および実装コードを含めて解説する。

セクション 1: 数式・理論 (summary形式, 約15%)

1.1 冷蔵庫システムの基本構成

家庭用冷蔵庫は以下の主要要素から構成される。

  1. 圧縮機 (Compressor)
    冷媒ガスを高圧に圧縮し、温度を上昇させる。

  2. 凝縮器 (Condenser)
    高温高圧の冷媒を外部に放熱し、液化する。

  3. 膨張弁 (Expansion Valve)
    液体冷媒を低圧に減圧し、蒸発器での吸熱を可能にする。

  4. 蒸発器 (Evaporator)
    冷媒が蒸発しながら庫内から熱を吸収する。

  5. 断熱庫内 (Insulated Compartment)
    熱容量および断熱特性を持つ冷却対象空間。

  6. 制御系 (Controller)
    庫内温度をモニタし、圧縮機のオン・オフを制御。

  7. 電力駆動系 (Electrical Drive)
    圧縮機モータの電力消費と効率をモデル化。

1.2 熱力学的理論背景

冷媒の循環は熱力学第1法則に基づくエネルギーバランスで記述される。

\[ Q_{in} - Q_{out} + W_{comp} = \Delta U_{system} \]

ここで、
- \( Q_{in} \)：蒸発器で吸収される熱 (庫内冷却)
- \( Q_{out} \)：凝縮器で放出される熱
- \( W_{comp} \)：圧縮機による仕事
- \( \Delta U_{system} \)：冷媒系の内部エネルギー変化

冷媒の状態変化は、比エンタルピー \( h \) および比エントロピー \( s \) によって表される。

圧縮機効率 \(\eta_{comp}\) は次式で定義される：

\[ \eta_{comp} = \frac{h_2 - h_1}{h_{2s} - h_1} \]

ここで、\( h_{2s} \) は断熱圧縮時の比エンタルピー。

1.3 熱伝達モデル

庫内の温度変化は単純化された熱容量モデルで表現する。

\[ C_{box} \frac{dT_{box}}{dt} = Q_{evap} - Q_{loss} \]

\[ Q_{loss} = k_{wall} (T_{box} - T_{amb}) \]

ここで、
- \( C_{box} \)：庫内熱容量
- \( k_{wall} \)：断熱壁の熱伝達係数
- \( T_{amb} \)：外気温
- \( Q_{evap} \)：蒸発器による吸熱量

1.4 制御理論

冷蔵庫制御は温度フィードバックを用いたオンオフ制御またはPID制御で記述される。

オンオフ制御ロジック：

\[ u(t) = \begin{cases} 1 & \text{if } T_{box} > T_{set} + \Delta T_{hyst} \\ 0 & \text{if } T_{box} < T_{set} - \Delta T_{hyst} \end{cases} \]

PID制御則：

\[ u(t) = K_p e(t) + K_i \int e(t) dt + K_d \frac{de(t)}{dt} \]

セクション 2: 完全コード (conclusion形式, 約85%)

以下にModelicaを用いた冷蔵庫モデル全体を提示する。
各構成要素はMSL標準ライブラリを使用し、冷媒特性には Modelica.Media.Refrigerants.R134a を採用する。

within RefrigeratorModel;

model HouseholdRefrigerator
  import Modelica.Fluid.Machines.Compressor;
  import Modelica.Fluid.Valves.ValveLinear;
  import Modelica.Fluid.HeatExchangers.SimpleHeatExchanger;
  import Modelica.Thermal.HeatTransfer.Components.*;
  import Modelica.Blocks.Logical.OnOffController;
  import Modelica.Blocks.Continuous.PID;
  import Modelica.Media.Refrigerants.R134a;
  import Modelica.Fluid.Interfaces.PartialTwoPort;
  import Modelica.Electrical.Analog.Basic.Resistor;
  import Modelica.Electrical.Machines.BasicMachines.DC_PermanentMagnet;

  // 冷媒定義
  replaceable package Medium = R134a;

  // ===== 冷媒循環系要素 =====
  Compressor compressor(
    redeclare package Medium = Medium,
    efficiency = 0.75,
    V = 0.0015,
    N = 3000);

  SimpleHeatExchanger condenser(
    redeclare package Medium = Medium,
    UA = 500,
    m_flow_nominal = 0.01);

  ValveLinear expansionValve(
    redeclare package Medium = Medium,
    Kv = 1e-5);

  SimpleHeatExchanger evaporator(
    redeclare package Medium = Medium,
    UA = 300,
    m_flow_nominal = 0.01);

  // ===== 熱容量・断熱庫内 =====
  Body fridgeBody(C = 20000, T(start = 293.15));
  ThermalConductor wall(k = 0.5);
  FixedTemperature ambient(T = 298.15);

  // ===== 制御系 =====
  OnOffController tempController(
    reference = 273.15 + 4,
    bandwidth = 2);

  TemperatureSensor tempSensor;

  // ===== 電気駆動系 =====
  DC_PermanentMagnet motor(
    V_nominal = 12,
    Ia_nominal = 2,
    w_nominal = 3000);

  Resistor powerLoss(R = 2);

  // ===== 接続定義 =====
equation
  // 冷媒流路接続
  connect(compressor.port_b, condenser.port_a);
  connect(condenser.port_b, expansionValve.port_a);
  connect(expansionValve.port_b, evaporator.port_a);
  connect(evaporator.port_b, compressor.port_a);

  // 熱ポート接続
  connect(evaporator.heatPort_b, fridgeBody.port);
  connect(fridgeBody.port, wall.port_a);
  connect(wall.port_b, ambient.port);

  // 温度計測と制御
  connect(tempSensor.port, fridgeBody.port);
  connect(tempSensor.T, tempController.u);
  connect(tempController.y, compressor.control);

  // 電力結合
  connect(motor.pin_p, powerLoss.p);
  connect(motor.pin_n, powerLoss.n);

  annotation (
    Documentation(info = "
    Household refrigerator model integrating fluid, thermal, and control domains.
    Refrigerant: R134a.
    Compressor driven by DC motor.
    Thermal body represents insulated compartment.
    OnOff control maintains target temperature.
    ")
  );
end HouseholdRefrigerator;

2.1 各コンポーネントの詳細説明

(1) 圧縮機 (Compressor)

  • 使用クラス: Modelica.Fluid.Machines.Compressor
  • パラメータ:
  • 容積流量 \(V = 0.0015 \text{ m}^3\)
  • 回転速度 \(N = 3000 \text{ rpm}\)
  • 効率 \( \eta = 0.75 \)
  • 出力: 冷媒の高圧側温度・圧力を生成。

(2) 凝縮器 (Condenser)

  • 使用クラス: Modelica.Fluid.HeatExchangers.SimpleHeatExchanger
  • 熱交換面積に対応する総合熱伝達係数 \(UA = 500\)
  • 外気との熱交換を模擬。

(3) 膨張弁 (Expansion Valve)

  • 使用クラス: Modelica.Fluid.Valves.ValveLinear
  • 流量係数 \(Kv = 1e-5\)
  • 圧力差に基づく冷媒流量制御。

(4) 蒸発器 (Evaporator)

  • 使用クラス: SimpleHeatExchanger
  • 熱交換係数 \(UA = 300\)
  • 庫内熱ポートと接続し吸熱を再現。

(5) 断熱庫内 (Body)

  • 使用クラス: Modelica.Thermal.HeatTransfer.Components.Body
  • 熱容量 \(C = 20000 \text{ J/K}\)
  • 初期温度 \(T_{start} = 293.15 \text{ K}\)
  • 熱損失は ThermalConductor を介して外気へ。

(6) 制御系

  • 温度センサ: TemperatureSensor
  • 制御器: OnOffController
  • 目標温度 \(T_{set} = 277.15 \text{ K}\)
  • ヒステリシス幅 = 2 K
  • 圧縮機のオンオフを制御。

(7) 電力駆動系

  • モータ: DC_PermanentMagnet
  • 定格電圧 12 V
  • 定格電流 2 A
  • 電力損失: Resistor(R=2)
  • 圧縮機駆動の電力消費を再現。

2.2 熱平衡の確認

冷媒循環系と庫内の熱バランスを確認するため、次の式を利用する：

\[ Q_{evap} = UA_{evap} (T_{box} - T_{evap}) \]
\[ Q_{loss} = k_{wall} (T_{box} - T_{amb}) \]
\[ C_{box} \frac{dT_{box}}{dt} = Q_{evap} - Q_{loss} \]

Modelicaコード上では Body および ThermalConductor により自動的にこの関係が再現される。

2.3 PID制御モデルの拡張例

オンオフ制御の代替として、PID制御ロジックを追加する場合：

PID tempPID(
  k = 2,
  Ti = 50,
  Td = 5,
  yMax = 1,
  yMin = 0);

equation
  connect(tempSensor.T, tempPID.u);
  connect(tempPID.y, compressor.control);

PID制御では圧縮機の回転速度を連続的に調整できるため、庫内温度変動が小さくなる。

2.4 シミュレーション設定例

simulateModel(
  model = RefrigeratorModel.HouseholdRefrigerator,
  startTime = 0,
  stopTime = 3600,
  numberOfIntervals = 500,
  tolerance = 1e-6,
  method = "Dassl");

出力変数:
- fridgeBody.T: 庫内温度変化
- compressor.power: 圧縮機消費電力
- motor.current: 駆動電流
- evaporator.Q_flow: 蒸発器吸熱量

2.5 エネルギー効率評価

冷蔵庫の性能指標としてCOP (Coefficient of Performance) を算出する：

\[ COP = \frac{Q_{evap}}{W_{comp}} \]

Modelicaでは以下のように定義できる。

Real COP;
equation
  COP = evaporator.Q_flow / compressor.power;

目標COP値は家庭用冷蔵庫では通常 2.0〜3.5 程度である。

2.6 モデル検証とパラメータ調整

  • 冷媒特性: Medium = R134a は一般的な家庭用冷蔵庫に適合。
  • 熱容量 \(C_{box}\) と断熱係数 \(k_{wall}\) の設定は実測データに基づいて調整。
  • 圧縮機効率・熱交換器UA値は製品仕様に対応。

2.7 拡張と将来課題

  1. 詳細流体分布モデル
    現状は単一流体ループで簡略化されており、庫内気流分布の影響は無視している。
    Modelica.Fluid.Vessels と Modelica.Fluid.Pipes を組み合わせることで詳細化可能。

  2. 相変化モデリング
    MSLでは冷媒の相変化を簡略化しているため、より精密な相境界モデルを追加するには Modelica.Media.Refrigerants.BaseProperties を拡張する必要がある。

  3. 外部熱負荷モデル
    開閉・食品投入などの外乱を HeatFlow ソースとして追加することで現実的挙動を再現可能。

セクション 3: 専門家分析に基づく統合考察

3.1 Node 4 の洞察の反映

  • 流体・熱・制御の3ドメイン統合を中心に設計。
  • Modelica.Fluid.Machines.Compressor を核として冷媒循環系を構築。
  • Modelica.Thermal.HeatTransfer を用いて庫内熱容量・断熱壁を定義。
  • OnOffController により温度保持制御を実装。
  • 冷媒特性は R134a パッケージを採用。

3.2 Node 5 の洞察の反映

  • Modelica.Fluid.Examples.AST_BatchPlant の構成を参考に流路を設計。
  • 電気モータ駆動ロスを Electrical.Machines で表現。
  • 温度センサによる制御フィードバックを明示化。
  • エネルギーバランスを HeatPort 連携で検証。

結論

本モデルは、Modelica標準ライブラリのみを用いて冷蔵庫の主要構成要素を統合的に記述したものである。
流体・熱・制御・電気の各ドメインを連携させることで、冷媒循環・庫内冷却・制御応答・電力消費の全体挙動を再現可能である。

今後の発展方向としては、詳細な流体メッシュモデル、相変化解析、外乱モデリングの導入が挙げられる。
